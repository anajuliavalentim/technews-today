# 🌎 TechNews Today

## 📰 Sobre o projeto

O **TechNews Today** é um portal de notícias sobre tecnologia, desenvolvido com HTML e CSS. O projeto tem como objetivo praticar conceitos de estilização e criação de layouts modernos, com foco na organização do conteúdo e na experiência do usuário.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

## ✨ Recursos e funcionalidades

- 🪟 **Glassmorphism:** efeito de vidro fosco utilizando `backdrop-filter`.
- 🎨 **Texto em degradê:** título estilizado com gradiente de cores.
- 📐 **CSS Grid:** organização dos elementos em um layout moderno.
- 📌 **Header fixo:** cabeçalho com `position: sticky`.
- 🎥 **Vídeo:** conteúdo multimídia integrado ao portal.
- 📩 **Newsletter:** seção para inscrição e recebimento de novidades.
- 📱 **Design responsivo:** adaptação do layout para celulares por meio de media queries.

## 🛠️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Mantenha os arquivos HTML e CSS na mesma pasta.
3. Confira se o nome do arquivo CSS está correto no link dentro do HTML.
4. Abra o arquivo `desafio10a.html` em um navegador para visualizar o portal.

## 📚 Objetivo da atividade

Praticar os recursos do CSS3, incluindo glassmorphism, gradientes, CSS Grid, posicionamento sticky e responsividade, sem utilizar frameworks, JavaScript ou modificar o HTML original.

## 👩‍💻 Desenvolvido para fins educacionais

Projeto desenvolvido como atividade prática de desenvolvimento web, com foco no aprimoramento das habilidades em HTML e CSS.
